Administração

Cadastre depositários, atribua bens e registre o progresso de destinação. Este é um site estático — suas edições ficam salvas neste navegador até serem exportadas e enviadas ao repositório.

⚠️ Como funciona: as alterações feitas aqui são salvas apenas no rascunho local deste navegador. Para que elas apareçam no site publicado para todos, clique em “Baixar dados atualizados” ao final da página e substitua os arquivos data/bens.json e data/depositarios.json no repositório (commit + push, ou upload pela interface do GitHub). O GitHub Pages republica o site automaticamente após o push.
